## Notes

- Pitch comes from audio analysis (YIN), not from file names. Many packs name files and map SFZ roots by written pitch, so the offset in the last column must be applied when building instruments.
- Percussion packs (drums, hats) are mostly unpitched; ignore their pitch columns.
- SFZ layers and round robins are the maximum on any one key, from the pack's root `.sfz` files (files that other `.sfz` files include are treated as fragments). Release-triggered samples and full-range add-ons are left out. Velocity ranges are counted as written, so packs that stack overlapping splits or gate layers behind a controller (drum kits with several mic layers, for example) read high. Packs without `.sfz` files show blanks.
- `env` and `ends_cut` look at the first 4 seconds plus the last 100 ms of each file.
